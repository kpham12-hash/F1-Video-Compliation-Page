# F1-Video-Compliation-Page
A video compilation web page that I built in the FreeCodeCamp Responsive Web Design Course that uses HTML. Each section on this webpage includes a description and video about each Formula 1 Team and the history behind them. Each video is embedded on the page and taken from an external source(YouTube). 

# Concepts Learned:

* iframe element
* allow attribute
* referrer policy attribute
* allowfullscreen title attribute
* Embedding external video element
